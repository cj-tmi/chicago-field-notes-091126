# Chicago Field Notes

A mobile-first, single-page travel planner for a Chicago wedding weekend, September 11–14, 2026.

## Features

- Official wedding itinerary with route links and suggested leave buffers
- Flight summary and airport timing without private confirmation details
- National Weather Service weekend forecast
- Persistent, device-local packing checklist
- Pescatarian-aware food shortlist and timed activity ideas
- Installable/offline-friendly static site
- `noindex` metadata and `robots.txt`

All user-facing sources are linked directly in the planner. The page contains no confirmation codes, contact details, or private credentials.
